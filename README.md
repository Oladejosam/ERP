# Construction ERP System

A complete enterprise-grade ERP platform for construction companies built with PHP 8.2+, MVC, PDO, Bootstrap 5, and MySQL.

## Features
- Authentication and user management
- Dashboard with KPIs and charts
- HR, payroll, attendance, leaves, and recruitment
- Procurement, suppliers, inventory, warehouse, and stock movement
- Projects, billing, accounting, budgeting, and reports
- Security, audit logs, notifications, document management, and backup

## Installation
1. Place the project in XAMPP under htdocs/ERP.
2. Create the database using the SQL files in the SQL folder.
3. Open http://localhost/ERP/public.
