# Construction ERP System

A complete enterprise-grade ERP platform for construction companies migrated to Node.js (v22), Express, and EJS with Bootstrap 5.

## Features
- **Landing Page**: Corporate website with company overview, portfolio metrics, and quick role access.
- **Authentication & Portals**: Role-based access control with one-click test logins (Super Admin, Managing Director, Site Engineer, Accountant, Procurement Officer, HR Manager).
- **Executive Dashboard**: Live KPIs, contract values, project completion progress, and inventory alerts.
- **Projects Portfolio**: Detailed BOQ budgets, daily site logs, progress percentages, and scheduling.
- **Warehouse & Inventory**: Real-time stock levels, low-stock reorder warnings, and material allocation to sites.
- **Procurement & Purchase Orders**: Purchase order generation, vendor invoice tracking, and goods received notes (GRN).
- **Requisitions Workflow**: Multi-tier approvals, delivery waybills, and dispatch notes.
- **HR & Payroll**: Department management, salary advance requests, staff loans, and monthly payroll batches.
- **Accounting & Billing**: Financial performance tracking, interim payment certificates (IPC), and disbursement vouchers.
- **Team Operations Chat**: Real-time operational communications channels.
- **Multi-Tenant Workspaces**: Dynamic branding and theme color customization.

## Running in AI Studio
1. Start development server: `npm run dev` (starts on port 3000)
2. Build applet: `npm run build`
